# Notes for Deck

Markdown notes for each project, in a pane beside your terminals. Open it from the **+** beside
your tabs, or a pane's menu, and choose **Notes**.

Each workspace folder has its own notes. A note is one `.md` file named after its title, in
Deck's config folder (`%APPDATA%\Deck\notes\<project>\`), so any Markdown editor can open them and
a Deck backup carries them. Notes save as you type.

- **+** after the last tab makes a note; double-click a tab to rename it; the X deletes it.
- Drag a tab to reorder. The order is kept per project on this machine.
- The editor previews as you write, with a formatting bar above it. Ctrl + wheel changes the
  text size.

Notes was built into Deck until 1.1. Notes written then are still where they were and show up as
soon as the plugin is installed.
